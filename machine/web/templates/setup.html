تطبيق جوجل (مرة واحدة)

إزاي أعمله؟ (خطوة بخطوة)
  1. افتح console.cloud.google.com واعمل مشروع جديد باسم content-machine.
  2. من APIs & Services ← Library فعّل الأربعة دول: YouTube Data API v3 و YouTube Analytics API و Google Drive API و Cloud Text-to-Speech API.
  3. من OAuth consent screen: اختار External، اكتب اسم التطبيق وإيميلك، وكمّل.
  4. مهم جداً: بعد ما تخلص، اضغط Publish app علشان يبقى In production. لو سبته Testing، الربط هيقف كل 7 أيام.
  5. من Credentials ← Create credentials ← OAuth client ID اختار النوع Desktop app.
  6. انسخ Client ID و Client secret والزقهم هنا.

  2. من Credentials ← Create credentials ← API key.
  3. اضغط على المفتاح ← API restrictions ← اختار Cloud Text-to-Speech API بس، واحفظ.
  4. الزقه هنا. اللوحة هتجربه على طول.
